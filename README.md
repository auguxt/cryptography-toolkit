## 📖 Overview

**Cryptography Toolkit** is an educational Python project designed to help students, cybersecurity enthusiasts, and developers understand how cryptographic algorithms work by implementing them from scratch.

Instead of treating encryption as a "black box", this repository demonstrates the internal logic behind classical and modern cryptographic algorithms using readable, modular, and well-documented Python code.

The project focuses on **education**, **experimentation**, and **understanding**, making it an excellent resource for beginners learning cybersecurity or cryptography.

## ⚠️ Educational Notice

This repository is intended for **educational purposes only**.

Although the RSA implementation uses modern cryptographic primitives provided by Python's `cryptography` library, this project should **not** be considered a complete production-ready encryption solution.

For production environments, always use well-tested cryptographic libraries, follow current security standards, and perform professional security reviews.
